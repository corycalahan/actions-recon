# Support

> **Note:** This project is maintained on a best-effort basis. There are no guarantees of any timeline or a response.

## Reporting a Bug

Please [open an issue](https://github.com/corycalahan/actions-recon/issues/new) on the repository.

Include:
- What you were doing when the problem occurred
- What you expected to happen vs. what actually happened
- Any relevant log output and screenshots
- Your Operating System (OS) information and Rust toolchain version (e.g. `rustc --version`, `cargo --version`)

## Requesting a Feature

Please [open an issue](https://github.com/corycalahan/actions-recon/issues/new) on GitHub with a description of the feature and the problem it would solve.

## Questions

For general questions, open an [issue](https://github.com/corycalahan/actions-recon/issues/new) on the repository.

## Contributing Tips

The `tips/` directory contains TOML files defining troubleshooting checks. Adding a new tip is the easiest way to contribute — refer to [tips/README.md](tips/README.md) for the schema and examples.
